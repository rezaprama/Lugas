Alat parafrasa dan sunting lokal.

Pilih pekerjaan dan bahasa keluaran, salin prompt ke model pilihan Anda atau hubungkan endpoint sendiri, lalu periksa apakah makna tetap sama.

Alat parafrasa lokal

Mode prompt saja dan pemeriksaan makna berjalan sepenuhnya di browser. Teks hanya dikirim bila Anda mengisi endpoint, dan hanya ke endpoint itu. Situs statis ini tidak menyimpan naskah dan tidak memakai analytics.

Tanpa batas harian: panggilan memakai model dan kuota Anda sendiri. Permintaan dihentikan setelah 90 detik.

Endpoint AI opsional (milik Anda)
Tempel teks, lalu buat prompt atau panggil endpoint Anda.

    Pemeriksaan makna

    Pemeriksaan leksikal atas angka, statistik, sitasi, kutipan, negasi, hedging, kausalitas, arah, dan cakupan. Hasil bersih bukan bukti; tetap baca hasilnya sendiri.

      Sebelum dikumpulkan

      Pastikan makna, sitasi, istilah teknis, kekuatan klaim, dan aturan kampus atau jurnal tetap benar. Lugas membantu menulis ulang; keputusan akhir tetap pada penulis.

      Mengapa local-first penting

      Banyak layanan parafrasa meminta penulis menempel draft ke form remote dan membayar untuk batas yang lebih longgar. Lugas memilih jalur berbeda. Aplikasi publik ini statis, bisa dipasang, dan gratis. Aplikasi dapat membuat prompt tanpa endpoint, atau memanggil hanya endpoint yang Anda masukkan.

      Keluaran bisa berbahasa Indonesia (EYD V) atau Inggris, terpisah dari bahasa antarmuka. Pemeriksaan makna berjalan di browser tanpa AI: angka dengan koma desimal, statistik, sitasi, kutipan, negasi seperti tidak, bukan, dan belum, hedging, hubungan vs sebab-akibat, arah, dan cakupan. Aplikasi tidak menyimpan naskah di server Lugas karena versi web ini tidak punya server naskah.

      Mengapa tidak ada batas harian

      Panggilan endpoint memakai model, token, dan kuota milik Anda sendiri, sehingga batas di browser tidak melindungi biaya siapa pun. Versi sebelumnya membatasi tiga panggilan per hari; batas itu dihapus. Permintaan dihentikan setelah 90 detik dan dapat dibatalkan.

      Layanan hosted dengan shared key sungguhan membutuhkan backend. Desain yang direncanakan adalah Worker API kecil, tabel D1 untuk kuota harian anonim, cache KV untuk keputusan rate-limit, Turnstile untuk menahan abuse, token provider hanya sebagai server secret, dan logging naskah mati secara default. Backend itu sengaja dipisahkan dari aplikasi statis saat ini.

      Gunakan hasil sebagai draft

      Selalu bandingkan keluaran dengan sumber. Verifikasi sitasi, angka, istilah, negasi, ketidakpastian, kekuatan klaim, dan aturan jurnal atau kampus sebelum dikumpulkan.
