Gunakan Lugas sebagai skill parafrasa lokal

Jalankan parafrasa prompt-first, pencarian frasa lokal, dan cek bukti tanpa bergantung pada SaaS parafrasa berbayar.

Pasang dari repositori

Paket skill berisi instruksi, skrip pencarian deterministik, dan katalog rilis. Pencarian inti berjalan secara lokal serta tidak memerlukan unggahan naskah. Tinjau repositori dan izin sebelum memasang ekstensi agen apa pun.

$skill-installer https://github.com/rezaprama/Lugas/tree/main/skills/lugas

Anda juga dapat mengkloning repositori dan mengarahkan agen ke skills/lugas/SKILL.md. Antarmuka baris perintah Python memakai katalog yang sama untuk pencarian yang dapat direproduksi.

Gunakan aplikasi web yang bisa dipasang

Alat Parafrasa dapat berjalan sebagai aplikasi browser. Tanpa endpoint AI, alat membuat prompt aman. Dengan endpoint, alat memanggil endpoint OpenAI-compatible atau Gemini-compatible yang dimasukkan pengguna. Token diproses di browser dan disimpan hanya bila pengguna memilih mengingat pengaturan.

Halaman statis hosted menerapkan batas tiga panggilan harian browser untuk panggilan endpoint. Ini bukan pengganti keamanan server-side. Shared public model key perlu backend dengan secret di server, penyimpanan kuota harian, perlindungan abuse, dan logging naskah mati secara default.

Nyatakan tujuan dan batasan dalam prompt

Prompt yang berguna menyebut tugas retoris, bagian naskah, jenis bukti, dan makna yang dilindungi. Prompt juga menjelaskan hal yang tidak boleh disimpulkan oleh agen. Contoh berikut dapat diadaptasi:

Penulisan ulang observasional

Rewrite this observational result without causal language. Preserve the estimate, interval, population, and citation. Explain any wording that would require a causal design.

Perlindungan makna

Paraphrase this sentence. Preserve citation, number, unit, negation, comparison direction, and uncertainty. Return a checklist showing each invariant.

Pencarian pola

Find three patterns for a cautious discussion interpretation. Prefer tentative or bounded claim strength and low risk. Show evidence requirements before the templates.

Baca keluaran sebagai usulan

Agen perlu mengidentifikasi gerakan, memberikan kandidat pola, menjelaskan kekuatan klaim, dan memperingatkan ketika bukti tidak memenuhi kebutuhan. Agen tidak boleh menciptakan hasil, referensi, metode, atau konsensus. Pola kausal bukan izin untuk membuat klaim kausal. Desain dan asumsi identifikasi harus telah membenarkannya.

Setelah mengadaptasi pola, bandingkan kalimat dengan bukti naskah. Verifikasi nama, sitasi, angka, satuan, arah, negasi, modalitas, populasi, waktu, dan keterbatasan. Minta bantuan ahli bila interpretasi bergantung pada pengetahuan bidang.

Jaga pencarian agar dapat direproduksi

Catat versi atau commit katalog, kueri, filter, dan ID pola terpilih ketika keputusan kata penting. Antarmuka baris perintah mengembalikan ID stabil untuk keperluan ini. Pencarian deterministik membuat katalog dan kueri yang sama menghasilkan urutan yang dapat diaudit.

lugas search "cautious interpretation" --limit 3
lugas explain RLX-QUA-001

Batas privasi

Pencarian lokal tidak mengirim teks naskah. Agen atau model yang mengelilinginya mungkin memiliki praktik data berbeda. Periksa sistem tersebut sebelum memberikan bahan rahasia, embargo, atau data identitas pribadi.
