# Responsible Paraphrasing

Paraphrasing changes expression while preserving meaning and attribution. It is not synonym substitution, patchwriting, or a method for reducing a similarity score.

## Choose a mode

- **Meaning-preserving rewrite:** improve clarity while keeping proposition structure stable.
- **Structural paraphrase:** change clause structure, information order, voice, sentence boundaries, or nominalisation where genre-appropriate.
- **Concision:** remove repetition without deleting claims, qualifications, or evidence.
- **Academic register:** replace conversational or inflated language with precise scholarly prose.
- **Evidence calibration:** weaken unsupported force or, only with explicit evidence, select a justified stronger form.
- **Phrase recommendation:** leave source text intact and return patterns with use conditions.
- **Move planning:** design communicative sequence before drafting sentences.

## Workflow

1. Determine whose idea is being expressed and where citation is required.
2. Read the full source unit needed for meaning, not an isolated sentence when context is available.
3. Build the protected-element inventory from [evidence-preservation.md](evidence-preservation.md).
4. Restate the proposition in plain semantic notes without echoing distinctive wording.
5. Draft from those notes using a genuinely different structure.
6. Compare meaning, attribution, qualification, and claim strength against the source.
7. Restore any required citation. Never invent one.

## Useful structural operations

- reorder given and new information;
- split an overloaded sentence or combine tightly linked short sentences;
- change active and passive voice when agency remains accurate;
- replace or introduce nominalisation only when it improves genre fit;
- turn a prepositional chain into a clause;
- make a hidden logical relation explicit without inventing it;
- remove empty transitions and inflated academic filler.

Do not mechanically apply several operations. Choose the smallest transformation that makes authorship and structure genuinely independent.

## Source-dependent requests

If the user supplies only another author's sentence, ask for or infer no missing evidence. Preserve attribution and state that the user must cite the source. If the passage is distinctive or quotation is more appropriate, recommend quoting rather than producing a close paraphrase.
